# Changelog

## 1.0.0

- Initial release of DrakesReskinIt
- Per-item icon swap via registered sprite registry (`IconRegistry`)
- Per-item tint/recolor with 12 preset colors + custom hex input
- Server-synced config (ServerSync) — same system as DrakesRenameit
- Admin/VIP bypass matching DrakesRenameit permission model
- Exclusion lists (ExcludedNames, ExcludedCategory) and ReskinAllowlist
- LockToOwner and ReskinClaimsOwner ownership mechanics
- Jotunn GUIManager panels: action menu, icon picker (scrollable grid), tint picker
